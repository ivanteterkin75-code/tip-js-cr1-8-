## 4. Задание 1. Одна программа — две среды

Вывод Node.js:

```text
Студент: Иванов Иван
Группа: ИКБО-00-00
Практическая работа: 1
JavaScript успешно запущен
Тип document: undefined
```

В браузере первые четыре строки совпадают, но последняя: `Тип document: object`.

**Объяснение.** `document` — объект DOM, он предоставляется браузером. В Node.js страницы нет, этой переменной в окружении не существует, поэтому `typeof document` даёт `"undefined"` (и не вызывает ошибку, так как `typeof` безопасен для необъявленных имён). Вывод в браузере находится только в Console, а не на странице.

## 5. Задание 2. Типы и преобразования

| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | `"82"` | `82` (строка) | string | `+` при наличии строки — конкатенация; число 2 превращается в `"2"` |
| `"8" - 2` | `6` | `6` | number | `-` не определён для строк, оба операнда приводятся к числу |
| `Number("8") + 2` | `10` | `10` | number | строка явно преобразована в число, затем сложение |
| `"12" > "3"` | `false` | `false` | boolean | обе строки: сравнение посимвольное, `"1" < "3"` |
| `12 === "12"` | `false` | `false` | boolean | строгое равенство не приводит типы; number ≠ string |
| `Number("")` | `0` | `0` | number | пустая строка (после обрезки пробелов) преобразуется в 0 |
| `Number("text")` | `NaN` | `NaN` | number | строку нельзя разобрать как число |
| `Boolean("false")` | `true` | `true` | boolean | любая непустая строка — истинна, содержимое не разбирается |
| `typeof null` | `"object"` | `object` | string | историческая особенность языка; `null` не является объектом |
| `typeof NaN` | `"number"` | `number` | string | `NaN` — особое значение типа number («не число» по смыслу, но number по типу) |

## 8. Отладка (`debug.js`)

**Исходный вывод (с ошибками):**

```text
Выполнено: 32
Осталось: -24
Контрольная сумма: 6
```

**Исправленный вывод:**

```text
Выполнено: 5
Осталось: 3
Контрольная сумма: 10
```

| Ошибка | Что наблюдалось | Причина | Исправление | Результат после исправления |
|---|---|---|---|---|
| Обработка количества задач | `completedTotal = "32"` (string), `Осталось: -24` | `"3" + "2"` — конкатенация строк; затем `"8" - "32"` приводит к числам | `Number(completedText) + Number(additionalText)` | `Выполнено: 5`, `Осталось: 3` |
| Граница цикла | `controlSum = 6` | условие `taskNumber < 4` не включает 4 | `taskNumber <= 4` | `Контрольная сумма: 10` |

Иллюстрация точки останова: `screenshots/debug-breakpoint.png` — **сделать самостоятельно** (DevTools → Sources → точка останова на строке `completedTotal`, в Scope видны `completedText: "3"`, `additionalText: "2"`, после шага — `completedTotal: "32"`).
