## Организация кода

- `task-service.js` — прикладные функции ПР2 (чистые, без DOM).
- `task-selectors.js` — `getVisibleTasks(tasks, filter)`: новый массив по фильтру `all`/`pending`/`completed`.
- `task-view.js` — `createTaskElement`, `renderTaskList` (через `replaceChildren`), `renderSummary` (через `getTaskStats`), `renderEmptyState`; весь текст выводится через `textContent`.
- `main.js` — состояние (`currentTasks`, `currentFilter`), `renderApp`, обработчики `handleTaskListClick` и `handleFilterClick`.

Полный список хранится в `currentTasks` (`main.js`), фильтр — в `currentFilter`. Событие обрабатывается делегированием на `ul#task-list` и `#task-filters` (подписка один раз), кнопка находится через `closest`. Сводка вычисляется в `getTaskStats` (сервис) для **всего** списка; количество «Показано» — длина выборки.

## Отладка и клавиатура

В `handleTaskListClick` точка останова ставится на строку `const rawId = card.dataset.taskId;`. Для клика по вложенной подписи кнопки «Выполнена» у задачи 4 значения: `event.target` — `span.action-label`; `event.currentTarget` — `ul#task-list`; `rawId = "4"` (string); после `Number` — `4`; действие `toggle`; найденная запись `{ id: 4, completed: false, … }`; `setTaskCompleted(currentTasks, 4, true)` вернул `{ ok: true, tasks: [...] }` — новый массив с изменённой записью. **Значения в этом пункте — логически выведенные из кода; их нужно подтвердить собственным запуском в DevTools и приложить скриншот.**

Клавиатура (проверено автоматизированно): `Tab` фокусирует кнопки по порядку; `Enter` на «Выполнена» у `id = 4` переключил статус (4 / 3 / 1 / 75.0%), фокус после перерисовки остался на кнопке `toggle` этой же карточки; `Space` переключил обратно (4 / 2 / 2 / 50.0%); после удаления `id = 7` карточки нет, и фокус перешёл на активный фильтр «Все».

Отказ через изменение атрибута в Elements: `data-task-id="777"` → сообщение «Задача с id = 777 не найдена», данные не изменились (4 / 2 / 2 / 50.0%); `data-task-id="4abc"` → «Некорректный идентификатор задачи: «4abc»», данные не изменились. Выбор любого фильтра перерисовывает карточки из реального массива и очищает сообщение.

## Вывод

Реализованы отрисовка списка и карточек, делегирование событий, фильтры, сводка и два вида пустого состояния; все проверки проходят (35 + 36). Изменение данных (`currentTasks`) и изменение DOM — разные действия: интерфейс всегда перерисовывается из массива, поэтому удаление через `element.remove()` или чтение статуса из текста кнопки не используются. Показательная ошибка: идентификатор из `dataset` — строка, и без `Number` с проверкой (`4abc` → `NaN`) состояние может быть повреждено.
